# Button

Four types: **Big** for the main action of a screen or dialog, **Ghost** for actions next to content, **Icon** for compact actions, and **Floating** for the round buttons that float over the page. They all share the same states: default, hover, pressed, disabled and focus (floating buttons add **open**).

Each type below has a Playground: change its properties and the button and its code update.

## Icon button

Compact actions where the icon is understood on its own. Four types, each with its own icon and meaning (the same as the Figma property **Type**):

| Type | Icon | Meaning | In the app |
|---|---|---|---|

| **Close** | `close` × (grey → red) | closes a banner or a dialog | Cerrar aviso · Cerrar |
| **Remove** | `close-filled` ⊗ (grey → red) | takes something out: a line, a message, the text of a field (a search field, in the future) | the rows of the desktop tables ("Eliminar factura 411") |

| | State | Variant | Default · Hover · Pressed · Disabled · Focus | Default |
| **Floating** | Type | Variant | Outline (white, blue ring) · Filled (blue) | Outline |

Icon and floating buttons have no visible text, but they always have a **Label for screen readers**: invisible on screen, read aloud as the button's name (`aria-label`). Write what the button does, as precisely as possible ("Eliminar factura 411", not just "Eliminar"). Left empty, it falls back to the default for the icon ("Más información", "Eliminar", "Cerrar").

| | Default | Hover | Pressed | Open | Disabled | Focus |
|---|---|---|---|---|---|---|
| **Floating · outline** | white, 3px `--primary` ring, blue icon | `--primary-tint` | tint + `--primary-dark` ring and icon | 2px white gap + 3px `--attention` ring | `--fill` + `--disabled` icon | yellow ring |

Hover lightens the colour on purpose, so the change of state is clearly visible. The default state is the one that meets WCAG AA (white on `--primary` 5.0 : 1, on `--attention` 4.5 : 1).

## Accessibility

- Use a real `<button>` (or `<a>` for navigation), never a `<div>`.
- Icon buttons **must** have an `aria-label` that says what they do ("Eliminar factura 411"); the icon gets `aria-hidden="true"`.
- Minimum target 24 × 24px (WCAG 2.2 AA). On mobile, icon buttons get a 44px touch area.
- Disabled buttons use `disabled`; if they must stay focusable, `aria-disabled="true"`.
- A label cut with "…" keeps its full text for screen readers; keep labels short anyway.
- **Ghost attention** (orange text) only on white, inside a card: on the grey canvas it reaches 4.1 : 1, below AA.
- **Floating buttons** say what they open (`aria-label`), and carry `aria-haspopup="dialog"` and `aria-expanded` (true while the panel is open).
