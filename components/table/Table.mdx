# Tables

The five tables of the app, each inside a **Card**. Every example uses the real data of the demo (2026).

| Table | Where | What you do |
|---|---|---|
| [Facturación](#facturación) | Facturación, a quarter or Resumen anual | type, change the status, delete, "+ Añadir" |
| [Gastos](#gastos) | Gastos, a quarter or Resumen anual | type, tick the 303, delete, "+ Añadir" |
| [Últimas facturas](#últimas-facturas) | Dashboard | change the status only |
| [Resumen anual](#resumen-anual) | IVA and IRPF, Resumen anual tab | read only |
| [Tax forms](#tax-forms) | IVA (Modelo 303) and IRPF (Modelo 130), a quarter | the result is calculated: you type only the compensation, the payment and the notes |

The data tables (Facturación and Gastos) have two controls:

| Control | Values |
|---|---|
| **View** | **Desktop**: the table · **Mobile**: the app doesn't show a table, it shows one block per invoice or expense (a record list, 390px frame) |
| **State** | **Editable**: a quarter (3T): cells are inputs, the dot changes the status, the row can be deleted · **Read only**: the Resumen anual tab (the whole year): plain text, nothing to change, no "+ Añadir" · **Empty**: a quarter with nothing yet (4T) |

On mobile, rows are not edited in place: a new invoice or expense is added through its form (<a href="./?path=/docs/app-components-dialog--dialog#mobile-forms" target="_top">Dialog › Mobile forms</a>); in the list only the status dot, the 303 checkbox and the trash button work.

Two tables, one under the other: **Facturas nacionales** (with IVA and IRPF) and **Facturas exentas de impuestos** (foreign clients: no IVA, no IRPF; the total is the base). Under them, the legend of the status dot (Cobrada · Pendiente), except in Resumen anual.

## Gastos

The same expenses in two lists: **Por cat. IRPF** (one table per category of the IRPF form) or **Por % IVA** (one table per rate). The columns change with the list and the category:

<Controls of={TableStories.Gastos} />

| | Columns |
|---|---|
| Por cat. IRPF | Núm. · Fecha · Proveedor · Concepto · Base € · IVA % · IVA € · Total € · 303 · delete |
| · 1. Seguridad Social / RETA | no IVA columns · the base is called **Cuota** · total only |
| · 10. Otros desgravables | adds **Objeto** in front |
| Por % IVA | Núm. · Fecha · Proveedor · Concepto · **Cat. IRPF** (`table__pick`: the number, the full list opens on click) · Base € · IVA € · Total € · 303 · delete |

- **303** (`table__check`): include the expense in the Modelo 303. Disabled when the expense has no IVA (0 % or Seguridad Social).
- Footer: Base · IVA · Total (Seguridad Social: Total). Empty: "Ningún gasto registrado".
- Each category title has its ⓘ with the rules of that category.

## Últimas facturas

The dashboard list: the **six newest invoices** (nacionales and exentas together), newest first. Number · client · date · base · status. Nothing is typed here: only the status dot works (Cobrada ↔ Pendiente), and the ⓘ explains that changing it updates every total. The card is half the dashboard width (540px). ## Tax forms

The quarter forms: **Modelo 303** (IVA, orange) and **Modelo 130** (IRPF, blue). Same structure for both; only the colour and the boxes change. The deadline is always orange. Everything is calculated from the tables except three things you type: the compensation (IVA only), the payment and the notes.

<Canvas of={TableStories.TaxForms} sourceState="none" />
<Controls of={TableStories.TaxForms} />

| Result | IVA · Modelo 303 | IRPF · Modelo 130 |
|---|---|---|
| **A ingresar** (`result--pay`, orange tint) | 3T: 1.778,23 € (with the compensation) · 1.930,03 € (without) | 3T: 2.683,99 € |
| **A compensar** (`result--credit`, green tint) | "A compensar próximo trimestre": IVA soportado bigger than IVA repercutido. Example: 1T, if its IVA expenses had been ticked for the 303 → 79,91 € | **No compensation block in IRPF.** The result is simply **negative** ("Sin pago fraccionado este trimestre", −433,73 €) and it's compensated in the annual return (Modelo 100). Example: 4T, if no more invoices arrive and the three RETA quotas are paid |
| **Sin actividad** (`result--none`, grey) | "Sin actividad con IVA": 2T (only foreign invoices, no 303 expenses) → 0,00 € | "Sin pago fraccionado este trimestre": 4T so far (3T paid, nothing new yet) → 0,00 € |

- **Compensación** (IVA only): the IVA a compensar of earlier quarters (151,80 € in the demo), with "Aplicar compensación". Applying it **changes the result**: it is subtracted from it (Sin actividad + 151,80 € → A compensar 151,80 €).
- **Registrar pago realizado** (Importe ingresado en Hacienda) only appears when there's something to pay.
- In the 1T and 4T examples the demo has no such quarter: the figures are built from its real records, as noted.

**Anatomy:** the card has no outer padding (`card--sectioned`). The header and each block pad themselves and are separated by hairlines.

## Accessibility

- **Every input and select in a cell has an `aria-label`** with the column and the row ("Base, factura 411"). The cells have no visible label of their own.
- Headers use `<th scope="col">`; the status and delete columns get hidden text (`sr-only`). Summary rows use `<th scope="row">`, so each amount is read with its concept and its quarter.
- The status dot is a `<button>` that says the status and what pressing does; in read only it's an image with the status in words. The delete and 303 controls name the row they act on.
- On mobile each record is a list item, and its figures a `<dl>`: each value is read with its label.
- Tax forms: every box is a `<dt>`/`<dd>` pair (code, label, amount); the result has `role="status"`, so a new result is announced, and its label says the state in words, not only the colour. The compensation amount has an `aria-label`; the payment and the notes have a `<label for>`.
