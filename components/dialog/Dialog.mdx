# Dialog

A window over the page that needs an answer before you go on. It's built on the browser's native `<dialog>` element, which keeps focus inside, closes with **Esc**, and dims the page behind it.

## Dialog

One component with all its controls, the same as the Figma component **Dialog**. The four kinds of dialog, with placeholder text (Title · Message text). Choose the **Type**; the **Button** list changes with it, and the size follows the type.

<Canvas of={DialogStories.Playground} sourceState="none" />
<Controls of={DialogStories.Playground} />

| Type | Colour | Size | Buttons | `role` |
|---|---|---|---|---|
| **Informative** | blue | `dialog--md` 640px | Continuar → · Entendido · Descargar ↓ · Guardar | `dialog` |
| **Attention** | orange | `dialog--sm` 400px | Entendido · Guardar | `alertdialog` |
| **Error** | red (`btn--danger`) | `dialog--sm` 400px | Confirmar · Entendido | `alertdialog` |
| **Multi-option** | blue | `dialog--md` 640px | Descargar ↓ · Guardar · Continuar → | `dialog` |

- **Cancelar** (optional) is a ghost button on the left, in the dialog colour (`dialog__actions--split`). Never two solid buttons.
- **Language toggle** (optional): the Esp / Eng switch above the title (`dialog__top`); in the app it changes the text of the dialog.
- **Multi-option**: the options are radios as cards (`choice` in a `choice-group`, see <a href="./?path=/docs/app-components-selectors--selectors" target="_top">Selectors</a>), the first one chosen.
- **Error** is not in the app yet: it's ready for actions that can't be undone (Eliminar año, a browser box today).

## Mobile forms

**Nueva factura** (nacional · exenta) and **Nuevo gasto**: on mobile you add a record through a full-screen dialog (title, ghost Cancelar, the fields, Guardar stuck to the bottom). On desktop you type straight into the table. The fields are the <a href="./?path=/docs/app-components-input--input" target="_top">Input › Field</a>, tinted, 20px apart. Choose the form in **Form**.

**Nuevo gasto** opens from the Gastos list, which has two views: **Por cat. IRPF** (the form opens with that category chosen) and **Por % IVA** (it opens with that rate). Its rules:

- Seguridad Social / RETA → % de IVA 0 %, locked, with the hint "La cuota de autónomos no lleva IVA."
- IVA 0 % → "Incluir en el 303" off.
- **Total gasto** (`field__total`: Sans 14 / 700 caps, in the field colour) updates as you type the base.

## Sizes

| | `dialog--md` (default) | `dialog--sm` |
|---|---|---|
| Use | Informative, multi-option, forms | Attention and error alerts |
| Width | `--dialog-w-md` 640px | `--dialog-w-sm` 400px |
| Padding | 32 top/bottom · 40 sides | 24 all round |
| Mobile | **Full screen**, actions stuck to the bottom (try **View → Mobile** in the Playground) | Stays centred, 16px from the edges |

## Spec

| | Value |
|---|---|
| Panel | `--surface` · 1px `--line` · radius 0 |
| Backdrop | `--overlay` 45% black |
| Top (`dialog__top`) | Optional, above the title, right-aligned: the language switch · 16px below |
| Header | Title on the left · optional action on the right (Cancelar ghost button on mobile forms) · 20px below |
| Title | `dialog__title` · Display · Light (24 / 300) |
| Body | `dialog__body` · Sans 16 · line height 1.6 · 16px between paragraphs (forms: 20px between fields) |
| Actions | `dialog__actions` · right-aligned · 16px gap · 24px above · `--split`: Cancelar on the left, the main action on the right |
| Max height | screen height − 48px, then the content scrolls |

## Accessibility

- `showModal()` makes the rest of the page **inert**: Tab stays inside the dialog and screen readers only read the dialog.
- **Esc** closes it, and focus returns to the button that opened it.
- The dialog is named by its title (`aria-labelledby`); alerts use `role="alertdialog"`.
- When the language switch changes the text, the dialog's `lang` changes too, so screen readers use the right pronunciation.
- The two choices of Guardar copia .html are real radio buttons in a `<fieldset>`: arrow keys move between them.
- **The focus ring is never removed.**
