# Input

The **fields where you type or choose a value**. Four components, the same as in Figma:

| Component | What it is | Use in the app |
|---|---|---|
| [Field](#field) | label above, a 40px box, an optional message below · **Dropdown** adds the chevron | **Text:** Proveedor · Cliente · Concepto · Número de factura · **Amount:** Base imponible en € · **Date:** Fecha · 2026 · **Dropdown:** % de IVA · Categoría IRPF |
| [Amount · small](#amount--small) | a 24px figure at the end of a tax-form row | Importe ingresado en Hacienda · Aplicar compensación (Modelo 303 · 130) |
| [Description](#description) | free text over several lines | Notas del trimestre · Notas de la declaración |
| [Field · inline](#field--inline) | the label on the left | Clientes (Cálculo del salario) |

**Not on this page:** checkbox, radio, choice card and switch are in <a href="./?path=/docs/app-components-selectors--selectors" target="_top">Selectors</a> · the mobile forms (Nueva factura · Nuevo gasto) are in <a href="./?path=/docs/app-components-dialog--dialog#mobile-forms" target="_top">Dialog</a> · cells you edit inside a table are in <a href="./?path=/docs/app-components-tables--tables" target="_top">Tables</a> · the Chatbot and Accessibility assistant forms use these fields with their own colours.

## Field

**One component for text, amounts, dates and dropdowns**: they only change in their content. The controls are the Figma properties: **Colour**, **Tinted**, **Value** (Filled, or Empty: the grey placeholder), **State** (Default, Hover, Error, Disabled, Focus), **Dropdown**, **Optional**, **Hint**, and the texts (Label, Text in the field, Hint text, Error text). Every text control starts with the real text of the app: replace it to try your own. Open the story to see its **Accessibility** tab.

**Colour & background.** The colour is the colour of the section: blue (Facturación, IRPF) or orange (Gastos, IVA). ## Amount · small

The two numbers you type inside the tax forms (Modelo 303 · 130); every other amount there is calculated. 24px, **Mono, right-aligned**, 160px wide, at the end of a row: `input input--sm input--num input--w-sm`. The **label is on the left** of the row. When it's **optional**, a checkbox comes before the label instead of "(opcional)": Aplicar compensación (Modelo 303). The required one is Importe ingresado en Hacienda (303 orange · 130 blue). Screen readers: the required one is named by its `<label for>`, the optional one by an `aria-label` that repeats the checkbox text.

## Description

Free text over several lines, always optional: the Notas of the tax forms (Notas del trimestre · Notas de la declaración). `<textarea class="input">`, at least 88px high, resizes vertically. The empty field shows a sentence in grey ("Criterios o decisiones de este trimestre..."). In the tax forms the box is **filled** in grey (`input--filled`: `--fill` background, `--line` border), so the notes read as a separate area of the form; use **Filled background** to switch it off.

## Spec

| | Value |
|---|---|
| Label | `field__label` · Sans 14 (16 on mobile) · `--text` · "(opcional)" `is-optional` in `--text-muted` |
| Box | `input` · `--input-h` 40px · padding `--input-pad-x` 12px · 1px `--line-strong` · radius 0 · `--surface` |
| Text | Sans 14 (16 on mobile, so iPhone doesn't zoom in) · placeholder `--text-muted` |
| Message | `field__hint` `--text-muted` · `field__error` `--error` · Sans 12 (14 on mobile) · empty → hidden |
| Hover | border `--text-muted` |
| Focus | border + 1px ring in the field colour **and** the yellow `--focus` ring |
| Error | `aria-invalid="true"` · border + 1px ring `--error` |
| Disabled | `disabled` · `--canvas` background · `--disabled` border and text |
| Tinted | `field--tinted` / `form--tinted` · `--primary-tint` / `--attention-tint` |
| Filled | `input--filled` · `--fill` background · `--line` border (Notas of the tax forms) |
| Amount · small | `input--sm` 24px · padding 8px · Mono 12 (also on mobile) · label on the left |
| Empty dropdown | the first option (`value=""`) in `--text-muted`, like a placeholder |
| Space between fields | `--space-20` |

## Accessibility

- Every field has a visible `<label for>`; the small amount with a checkbox has an `aria-label` instead.
- Required fields carry `aria-required="true"`; optional ones say "(opcional)" in the label, so it's read too.
- Hints and errors are linked with `aria-describedby`, so they're read when the field gets focus. Errors also set `aria-invalid="true"` and always say what's wrong in words.
- Focus is shown twice: the coloured border **plus** the yellow ring.
- Dates use `inputmode="numeric"`, amounts `inputmode="decimal"`: phones open the right keypad.
- The Total gasto is `aria-live="polite"`: screen readers read the new total.
