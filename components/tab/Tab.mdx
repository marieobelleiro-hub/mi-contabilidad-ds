## When to use

| Use | Role | Example |
|---|---|---|
| **Navigation**: goes to another section | `<a aria-current="page">` inside `<nav>` | Dashboard · Facturación · Gastos · IVA · IRPF |
| **Tabs**: switch the content shown on the same page | `<button role="tab" aria-selected>` inside `role="tablist"` | Resumen anual · 1T · 2T · 3T · 4T |
| **Toggle**: choose between 2 views | same as tabs | Por cat. IRPF / Por % IVA |
| **Selector** (mobile): the current choice, opens a menu | `<button aria-expanded>` + a list | Section · Period |

## Colour code

The active tab takes the colour of what the section is about:

| Section | Is about | Colour | Active style | Class (code) |
|---|---|---|---|---|
| Dashboard | the whole app | **green**, black text | filled | `tab--brand` |
| Facturación | **income** | **blue**, white text | filled | `tab--primary` |
| IRPF | **income** (tax on what you earn) | **blue** | outline | `tab--primary tab--outline` |
| Gastos | **expenses** | **orange**, white text | filled | `tab--attention` |
| IVA | **payments to be made** | **orange** | outline | `tab--attention tab--outline` |
| Period selector | neutral | **grey**, black text | filled | `tab--neutral` |

The outline marks the tax sections (IVA, IRPF), so they look different from the sections where you enter data.

## Year strip

A **composition** (molecule) of year tabs in a row: `year-strip` with `role="tablist"`, 16px gap, the tabs share the width equally.

| Rule | |
|---|---|
| How many | **6 years** |
| Order | Newest on the **left**, oldest on the right |
| Current year | Read from the **device's clock**: on 1 January the new year becomes active by itself |
| Active years | The current year and the years before it: **selected** or **unselected** |
| Future years | **Disabled** until their year starts |
| Selection | **Exactly one** year is selected, always (by default the current year) |
| As the years pass | The strip starts at 2025; once the current year passes the 6th year, it moves forward and the oldest year leaves |

Today ({YEAR_INFO.now}) the strip shows {YEAR_INFO.years[0]} → {YEAR_INFO.years[5]}: **{YEAR_INFO.active.length} active** ({YEAR_INFO.active.join(', ')}), the rest disabled. In the **Selected year** control only the active years can be chosen; you can also click a year in the preview.

## Accessibility

- Use real elements: `<a>` for navigation, `<button role="tab">` for tabs — never a `<div tabindex="0">`.
- The selected state is set with `aria-selected="true"` (tabs) or `aria-current="page"` (navigation), so screen readers announce it. The CSS reads those attributes directly.
- Only the selected tab is in the Tab order; ← → move between tabs.
- The bold weight on the selected tab adds a second cue besides colour.
